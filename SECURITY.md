# Security policy

PLC_FX talks to industrial hardware over a serial port, so please report anything that could lead
to unsafe or unexpected machine behaviour.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's private
[security advisory form](https://github.com/shaxboz1011/C-and-Mitsubishi/security/advisories/new)
instead. Include the app version, your Windows version, the PLC model and clear steps to reproduce.

We aim to acknowledge reports within 7 days.

## Supported versions

Only the latest version on the default branch receives fixes.

## Safety note

This is a control application for real equipment. Always keep a physical emergency stop within
reach, and only connect it to a PLC and machine you are authorised to operate.
